Figma security, all in the Figma PR:
1. Requests that carry `X-Figma-Token` no longer use `-L`. Only the token-less pre-signed image download follows redirects. Everything is HTTPS-only now (`--proto`/`--proto-redir =https`), with plain HTTP allowed only for a loopback test `apiBase`.
2. `figma.setToken` creates the token file with mode 0600 instead of writing and then running chmod. The bridge's pairing-code file gets the same treatment.
3. The pairing code comes from the OS CSPRNG (`getrandom`, no modulo bias). After 5 wrong codes in a row the bridge locks for 60 s (429). Bodies are capped at 64 MB (413). `--code` needs 8+ characters, and the `Host` header must be loopback.

curl stays for the optional REST path for now. We have no HTTP/TLS stack in-tree, and model downloads already use the system curl the same way (the token goes in on stdin, never on the command line). The plug-in and MCP paths need neither a token nor curl. I'm happy to move both to a pure-Rust client in a follow-up if you'd prefer.
