# Elias AE keyboard preset

The user-authored **Elias AE** preset is included on macOS and Windows, even when
an existing settings file has no custom presets. Select it in Keyboard Shortcuts.
Existing presets named Elias AE are preserved, including local edits. The current
Mac preset remains active and unchanged. `Cmd` maps to Control on Windows;
`Physical+` bindings keep the same key position across layouts.

The preset includes Shift+F → Fit. This command currently has Composition scope:
focus the Composition viewer before pressing it. Timeline focus does not dispatch it.
This is a panel-focus restriction, not an absent shortcut.

Source: Elias’s own EffectCraft shortcuts.json, 2026-10-15; no Adobe asset is bundled.
Windows hardware behavior remains unverified.
